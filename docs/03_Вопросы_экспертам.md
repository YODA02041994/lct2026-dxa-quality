## Решаем сами, не спрашиваем

- Дубликаты файлов → строка на каждый файл, дедуп внутри.
- Плоская или древовидная структура → рекурсивный загрузчик, ест обе.
- Область и сторона бедра → по картинке; суффиксы имени файла — подсказка.
- Интернет при сборке → отдаём Dockerfile **и** `docker save`.
- Битые файлы → `processing_status = Failure`, без падений.
- SourceCraft, квота Yandex Cloud → организационное, в чат.
