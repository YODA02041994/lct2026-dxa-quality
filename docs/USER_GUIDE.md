# Руководство пользователя

Для кого: лаборант и врач кабинета денситометрии, специалист по контролю качества.

## 1. Веб-страница

1. Откройте адрес сервиса (прототип: https://docsemenov.ru/dxa/).
2. Перетащите на страницу файлы `.dcm` или zip-архив с папками исследований. Можно несколько файлов сразу.
3. Нажмите «Проверить». Через несколько секунд появится таблица: строка на каждый файл.

Что в строке:

| Поле | Значение |
|---|---|
| область | поясничный отдел позвоночника или проксимальный отдел бедра (R/L) |
| класс | «норма», «нарушение» или `Failure`, если файл не прочитан |
| отметка «проверить» | один из критериев близок к порогу — решение стоит посмотреть глазами |
| тип нарушения | официальная формулировка; ниже серым — протокол измерений, красным — совет лаборанту |
| вероятность · критерии | итоговая вероятность нарушения и вероятности по каждому критерию |
| снимок | открыть снимок с разметкой |
| разметка областей измерения | сервис предлагает, где должны стоять области L1–L4 или шейки бедра; «подтвердить» или «отклонить» |

Кнопки `results.xlsx` и `results.csv` скачивают таблицу в формате постановщика, кнопка «серии DICOM (zip)» — архив
дополнительных серий: DICOM-серия с разметкой, DICOM SR и PNG.

## 2. Как читать снимок с разметкой

- жёлтые точки — анатомические ориентиры (тела позвонков, гребни, головка, вертелы, диафиз);
- голубая линия — ось позвоночника или диафиза; серая вертикаль — ось кадра;
- красная рамка — найденный посторонний предмет, число — уверенность;
- зелёные четырёхугольники — предложенные области измерения: тела L1–L4 или шейка бедра;
- вверху — вердикт и вероятности критериев с порогами, внизу — измерения.

## 3. Подтверждение разметки

Сервис предлагает разметку областей измерения по найденным ориентирам. Специалист смотрит её на снимке и нажимает
«подтвердить» или «отклонить»; при отклонении можно написать причину. Решение попадает на лист `разметка` таблицы `results.xlsx`.
При пакетной обработке без веб-страницы разметка записывается со статусом «предложено, ждёт подтверждения».

## 3а. Что делать при нарушении

| Тип нарушения | Действие лаборанта |
|---|---|
| Некорректная укладка (позвоночник) | сместить поле: в кадре должны быть Th12 с рёбрами и гребни подвздошных костей, L1–L4 целиком |
| Не выровнена ось позвоночника | выровнять пациента по средней линии стола |
| Присутствуют посторонние предметы | убрать металл и одежду с фурнитурой, переснять |
| Некорректная укладка (бедро) | довернуть стопу внутрь на 15–25° и зафиксировать; бедро параллельно оси стола |
| Некорректная область интереса (бедро) | расширить поле: головка, большой вертел и не менее 2,5 см диафиза ниже малого вертела |

## 4. Пакетная проверка архива

```bash
docker run --rm -v "$PWD/in:/in" -v "$PWD/out:/out" dxaqc run -i /in -o /out --overlays --sr
```

В `out/`: `results.xlsx` (лист `results` — по файлам, лист `по исследованиям` — что переснять), `series/` — дополнительная серия DICOM
со снимками и разметкой, `overlays/` — те же снимки в PNG,
`sr/` — DICOM SR с текстом заключения для загрузки в PACS, `additional_series.zip` — серии одним архивом, `run.log` — журнал.

## 5. Режимы порогов

| Режим | Когда использовать | Чувствительность / специфичность |
|---|---|---|
| обычный (по умолчанию) | аудит архива, отчётность | 0,78 / 0,89; помечается 30 % снимков |
| `--mode sensitive` | контроль на потоке, когда пропуск дороже перепроверки | 0,94 / 0,38; помечается 71 % снимков |

## 6. Границы применимости

Сервис оценивает только качество съёмки. Он не рассчитывает плотность кости и не ставит диагноз. Сколиоз, перелом и эндопротез
нарушением укладки не считаются. Проверка выполнена на аппарате GE Lunar Prodigy Advance.
