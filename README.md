# ЛЦТ-2026 · Задача №4 · Контроль качества денситометрии (DXA)

ИИ-сервис, который принимает DICOM-исследование денситометрии и отвечает: какая это анатомическая
область, годен ли снимок для клинической интерпретации, и если нет — какое именно нарушение
укладки/позиционирования/поля сканирования обнаружено.

**Заказчик:** Центр диагностики и телемедицины Департамента здравоохранения Москвы.
**Хакатон:** «Лидеры цифровой трансформации 2026», задача от города №4.
**Призы:** 1 000 000 / 600 000 / 400 000 ₽. **Дедлайн сдачи: 29 сентября 2026, 23:59 МСК.**

> Репозиторий **приватный**: внутри обезличенные медицинские изображения и материалы организатора,
> выданные под пароль. Не делать публичным, не форкать в открытые аккаунты.

## Данные

`data/raw/` — то, что выдал организатор 14.09 (как есть):

- `train.zip` — 100 исследований, 499 DICOM, **252 уникальных изображения** (остальное — дубликаты серий);
- `разметка.xlsx` — экспертная разметка, лист «Калибровка», строка = исследование;
- `test.zip` — 3 файла «Для теста» для отладки загрузчика, область зашита в имя файла.

```bash
python scripts/unpack_data.py                 # → data/work/ (в git не попадает)
PYTHONPATH=src python scripts/audit_dataset.py  # цифры из docs/02
```

Закрытый тестовый набор участникам не выдаётся; финальные метрики считает организатор.

## Быстрый старт разработчика

```bash
python -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
python scripts/unpack_data.py
PYTHONPATH=src python scripts/audit_dataset.py
```

## Что сдаём 29.09 (чеклист из ТЗ)
